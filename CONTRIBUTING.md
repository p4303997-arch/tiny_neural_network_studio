# Contributing

This project is a teaching tool.
Small improvements are welcome.

## How to contribute
1. Fork the repository.
2. Create a feature branch.
3. Make a focused change.
4. Test the app by opening `index.html` in a browser.
5. Open a pull request with a short description.

## Contribution guidelines
Keep sentences short in user facing explanations.
Avoid adding heavy dependencies.
Prefer plain browser JavaScript.
Keep datasets and examples within the documented ranges.
