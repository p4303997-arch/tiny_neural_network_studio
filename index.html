The fixed rule

Each neuron always mixes inputs using weights, adds a bias, then passes through an activation gate. Training does not change the rule. Training changes the numbers.

Architecture translation

Weights are priorities. Bias is baseline preference. Hidden critics are internal mini rubrics that can form concepts like heat stress, comfort lift, or glare pressure.

Auto-grow

If loss plateaus, the model might be too small. Auto-grow adds a critic to increase capacity. This is similar to choosing a bigger model when a small one cannot fit the brief.
